# Accuracy Measurement System

## Overview

The accuracy measurement system compares participant selections against ground truth answers to calculate precision, recall, and F1 scores for each task completion.

## How It Works

### 1. Ground Truth Generation

Ground truth answers are generated by:
1. Parsing task descriptions to extract filters
2. Executing queries with those filters
3. Storing matching result IDs in the database

**Run ground truth generation:**
```bash
cd backend
source venv/bin/activate
python generate_ground_truth.py
```

### 2. Accuracy Metrics

For each task completion, the system calculates:

- **Precision**: Of the items selected by the participant, how many were correct?
  - Formula: `True Positives / (True Positives + False Positives)`
  - Range: 0.0 to 1.0 (higher is better)

- **Recall**: Of the correct items, how many did the participant find?
  - Formula: `True Positives / (True Positives + False Negatives)`
  - Range: 0.0 to 1.0 (higher is better)

- **F1 Score**: Harmonic mean of precision and recall
  - Formula: `2 * (Precision * Recall) / (Precision + Recall)`
  - Range: 0.0 to 1.0 (higher is better)

- **True Positives**: Items selected that are correct
- **False Positives**: Items selected that are incorrect
- **False Negatives**: Correct items that were not selected

### 3. Example

**Task**: "Find movies released after 2015 with runtime under 100 minutes"

**Ground Truth**: [Movie ID 1, Movie ID 2, Movie ID 3, Movie ID 4, Movie ID 5] (5 correct answers)

**Participant Selected**: [Movie ID 1, Movie ID 2, Movie ID 6, Movie ID 7]

**Metrics**:
- True Positives: 2 (IDs 1 and 2)
- False Positives: 2 (IDs 6 and 7)
- False Negatives: 3 (IDs 3, 4, 5)
- Precision: 2 / (2 + 2) = 0.5 (50%)
- Recall: 2 / (2 + 3) = 0.4 (40%)
- F1 Score: 2 * (0.5 * 0.4) / (0.5 + 0.4) = 0.44

## Interpreting Results

### High Precision, Low Recall
- Participant is selective but misses many correct items
- May indicate interface is hard to use or filters are too restrictive

### Low Precision, High Recall
- Participant finds many correct items but also selects incorrect ones
- May indicate interface returns too many results or lacks precision

### High Precision, High Recall
- Ideal: Participant finds most correct items with few mistakes
- Indicates effective interface

### Low Precision, Low Recall
- Participant struggles with the task
- May indicate interface usability issues

## Notes

- Tasks without ground truth will have `NULL` values for accuracy metrics
- Ground truth is generated once and stored in the database
- To regenerate ground truth (e.g., if tasks changed), use `--force` flag
- The system handles both movies and books datasets automatically

## Troubleshooting

**No accuracy metrics showing:**
- Run `python generate_ground_truth.py` first
- Check that tasks have ground truth: `SELECT task_id, ground_truth FROM tasks LIMIT 5;`

**Ground truth seems incorrect:**
- Check task descriptions are clear and parseable
- Review extracted filters in the generation output
- Manually verify a few queries

**All metrics are 0:**
- Check that participants are selecting items (not submitting empty)
- Verify ground truth IDs match the dataset being used
